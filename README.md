# Modular Office Sales & Marketing
Plain HTML/CSS/JS, no animation, no build step.
Run locally: `python3 -m http.server 8000` in this folder, then open http://localhost:8000
Deploy: upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages). index.html must be at the root.
WhatsApp: https://wa.me/447386945522   Email: Modofficesales@gmail.com
Images: assets/images/ (hero.webp and partner-1..3.webp are from your supplied frames; replace with the client's own photos if wanted).
Form: js/script.js. It validates, then opens the visitor's email app addressed to Modofficesales@gmail.com. To receive submissions directly without the visitor's email app, connect a form service (Formspree, Netlify Forms) in the submit handler.
